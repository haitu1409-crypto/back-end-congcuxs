# Advanced Soi Cầu Service Documentation

## Tổng quan

Advanced Soi Cầu Service là hệ thống dự đoán soi cầu tích hợp 7 phương pháp soi cầu cao cấp.

## 7 Phương pháp

1. Pattern Recognition - Jaccard Similarity
2. Cycle Analysis - Trigonometric functions
3. Hot/Cold Analysis - Frequency analysis
4. Adjacent Number - Markov chains
5. Mathematical Sequences - Arithmetic sequences
6. Statistical Distribution - Z-score analysis
7. Time-Series - Autocorrelation

## Sử dụng

```javascript
const service = new AdvancedSoiCauService();
const probs = await service.predict(date, 100);
```
